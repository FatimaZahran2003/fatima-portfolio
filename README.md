# Fatima Zahran Portfolio

Responsive portfolio starter built with React, Vite, and custom CSS. It includes a dark near-black background, botanical green accents, mobile navigation, project detail modals, and **8 replaceable image placeholders**.

## Run locally
Requirements: Node.js 18+ (Node.js 20+ recommended) and npm.

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Replace the 8 project images
The eight SVG placeholders are in `public/images/`:
- `geniflora-01.svg` to `geniflora-04.svg`
- `yallaeat-01.svg` to `yallaeat-04.svg`

You can replace them with your own screenshots. Easiest method: keep the same filenames and extensions as `.svg`, or update the image paths in `src/App.jsx` if you use `.png`, `.jpg`, or `.webp`. For screenshots, 16:10 or 4:3 images generally work well.

## Before publishing
1. In `src/App.jsx`, replace `YOUR_EMAIL@example.com` with your professional email address.
2. Replace the LinkedIn and GitHub URLs with your actual profile URLs.
3. Add your real project screenshots and confirm the project copy reflects completed functionality.
4. Add a CV link only after placing the correct CV file under `public/`.
5. Do not publish until the contact links and all project details have been checked.

No real email, project demo URL, or source-code URL is fabricated.
